# Hearth Launcher

Hearth is an in-development Windows desktop launcher for Minecraft: Java Edition, built with Rust and Tauri.

It provides isolated game instances, performance presets, compatibility-aware Modrinth mod installation, Iris shader support, and Distant Horizons configuration.

When a user chooses to connect their account, Hearth uses Microsoft's standard authentication flow to verify Minecraft: Java Edition ownership and obtain the session required to launch the game. Hearth does not collect Microsoft passwords or operate an authentication server.

Hearth does not promise unlimited rendering, universal mod compatibility, or guaranteed performance improvements.
